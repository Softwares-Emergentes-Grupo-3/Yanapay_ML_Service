<h1>Yanapay Machine Learning Model Service</h1>
<p>
  This repository contains the code for the <strong>Yanapay Machine Learning Model Service</strong>, a RESTful API designed to predict the risk of potato diseases based on an image of a potato leaf.
</p>

<h2>Installation</h2>
<p>
    To get started, follow these steps:
</p>

<ol>
  <li>Clone the repository:</li>
  <pre><code>git clone <a href="https://github.com/Softwares-Emergentes-Grupo-3/Yanapay_ML_Service.git">https://github.com/Softwares-Emergentes-Grupo-3 Yanapay_ML_Service.git</a></code></pre>
    
  <li>Install the required dependencies:</li>
  <pre><code>pip install -r requirements.txt</code></pre>

  <li>Run the service:</li>
  <pre><code>python main.py</code></pre>

  <li>Open your web browser and navigate to <a href="http://localhost:8000">http://localhost:8000</a> to access the API.</li>
  
  <li>For a more interactive experience, you can use the Swagger UI provided by FastAPI:</li>
  
  <li>Access the API documentation at <a href="http://localhost:8000/docs">http://localhost:8000/docs</a></li>
</ol>
